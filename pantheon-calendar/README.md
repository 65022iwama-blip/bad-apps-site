# Pantheon Calendar

月の満ち欠けに合わせた、14日周期の神話暦。
今日が14柱のどの神の日かを、回せる円盤で表示する。

## 動かし方

`index.html` をブラウザで開くだけ。ビルドもインストールも不要。
（フォントだけネットから読む。オフラインでも代わりのフォントで動く）

## ホーム画面に置く（iPhone）

ホーム画面のアイコンから、アプリのように全画面で開ける。開くたびに今日の神が出る。

1. iPhone の Safari で https://65022iwama-blip.github.io/bad-apps-site/pantheon-calendar/ を開く
2. 共有ボタン（□に↑）→ **ホーム画面に追加**

`main` に入ると、`.github/workflows/pages.yml` がこのフォルダを公開用リポジトリ `bad-apps-site` へ写して公開する（1〜2分かかる）。`bad-apps` 本体は非公開のまま。

- 一度開けば、電波がなくても開ける（`sw.js` が端末にしまっておく）
- 裏に残ったアプリを開き直したとき、0時をまたいだときは今日に戻る
- 中身を直して push すると、**2回目に開いたとき**に新しい版になる

## 暦のルール

| 項目 | 内容 |
|---|---|
| 巡りの始まり | 新月の日と満月の日。その日が1日目（Nyx） |
| 1巡りの長さ | 日付で数えて13〜16日（毎回変わる） |
| 15日目以降 | 「延長日」として14日目（Kronos）のまま |
| 満ちる巡り／欠ける巡り | 新月始まり／満月始まり |
| 日付の区切り | 端末のタイムゾーンの0時 |

新月・満月の日時は `moon.js` が天文計算で出す（外部APIなし、誤差数分）。

## ファイル構成

```
index.html        画面の骨組み。scriptの読み込み順に意味がある
css/style.css     見た目
js/pantheon.js    14柱のデータ（名前・役割・色・紋章・神話）  ← 内容を変えるならここ
js/moon.js        新月・満月の計算、月の形のSVG
js/cycle.js       日付 → 「巡りの何日目か」
js/feedback.js    カチッという音と振動
js/app.js         盤の組み立て、表示更新、ドラッグ操作
manifest.json     ホーム画面に置いたときの名前・色・アイコン
sw.js             一度開いたファイルを端末にしまう（オフライン用）
icons/            ホーム画面のアイコン（icon.svg が元絵、PNG はそこから書き出したもの）
```

依存の向き：`pantheon.js` / `moon.js` → `cycle.js` → `app.js`（`feedback.js` は `app.js` から呼ぶ）

## よく触る場所

- **神を入れ替える・文言を変える** → `js/pantheon.js` の `GODS`。並び順がそのまま1〜14日目
- **紋章を描き直す** → `js/pantheon.js` の `EMBLEMS`（64×64 の SVG path）
- **回しやすさ** → `js/app.js` 冒頭の `DRAG_RESISTANCE`（小さいほど重い）
- **カチッの強さ** → `js/app.js` 冒頭の `DETENT_STRENGTH`（大きいほど区画に吸い付く）
- **クリック音** → `js/feedback.js` の `playClick()`（`frequency` で音の高さ）
- **ファイルを足した・名前を変えた** → `sw.js` の `FILES` にも書き、`CACHE` の番号を上げる

## 操作

- 盤をドラッグ：時計回り＝過去、反時計回り＝未来。1区画ごとに音と振動
- `‹` `›` `今日` ボタン
- 「神話をひらく」：象徴の品と神話の一場面
- 「アイコンに今日の日数を出す」：ホーム画面から開いたときだけ出るボタン。通知を許可すると、アイコン右上に巡りの何日目か（1〜16）が付く。数字は開いたときに更新（iOS 16.4〜）

## わかっている制限

- **iPhoneでは振動しない（音だけ）。** iOSはウェブページからの振動（`navigator.vibrate`）を許していない。Androidのブラウザでは振動する。
- **`index.html` をファイルのまま開いたときはオフライン用のしまい込みが動かない。** `sw.js` は http(s) で配ったときだけ働く。
