# ガマン階段（仮）

スマホを我慢した時間だけ階段を昇るPWA。昇るほど景色が変わる（夜の街 → 深い森 → … → 光の門）。景色は20種類。次の景色までの間隔は 1,2,2,3,…,15階 と広がり、140階で光の門（js/scenes.js の ZONE_START）。

- 1日の目標より少なかった分（分）だけ段を昇る。60段（1時間）で1階
- 目標をこえた日は、こえた分の半分だけ落ちる
- 記録は夜にスクリーンタイムのスクショを入れるだけ。数字は Tesseract.js が端末の中で読み取る（手入力もできる）
- 記録はその端末の中（localStorage）だけ。ログインなし

## ファイル
- `js/scenes.js` 景色と階段の描画（景色を足すときは ZONES に1行＋描く関数）
- `js/ocr.js` スクショから「3時間12分」などを読み取る
- `js/app.js` 記録・アニメーション・画面

## 確かめ方
`npx http-server -p 5174` を動かして http://localhost:5174 を開く。
`?f=35` をつけると、記録と関係なく35階の景色を見られる。
